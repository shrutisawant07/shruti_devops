# Simple Student Management System

A small Java console program for adding and viewing student names. Student data
is kept in memory and is cleared when the program exits.

## Requirements

- Java 17 or newer
- Maven 3.8 or newer

## Build and test

From this folder, run:

```text
mvn test
```

## Run

From this folder, run:

```text
mvn package
java -jar target/simple-student-management-1.0.0.jar
```

Choose `1` to add a student, `2` to list students, or `0` to exit.
